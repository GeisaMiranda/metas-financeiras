# Política de Privacidade — Metas Financeiras

Última atualização: novembro de 2026.

**Quais dados o app usa:** nome, e-mail, senha, metas, valores registrados e pontuação.

**Onde ficam:** somente no seu aparelho, em banco de dados local. O app não envia seus dados para servidores nem para terceiros e não usa anúncios ou ferramentas de rastreamento.

**Senha:** guardada de forma protegida (hash com sal), nunca em texto simples.

**Notificações:** o app só envia o lembrete diário se você ativar e permitir no celular. Você pode desligar quando quiser em Perfil.

**Exclusão:** desinstalar o app apaga todos os dados. Você também pode excluir cada meta dentro do app.
