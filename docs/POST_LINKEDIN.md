Concluí mais um projeto da faculdade: o **Metas Financeiras**, um app mobile (Android e iOS) para planejar objetivos, guardar dinheiro e ganhar pontos com desafios de economia. 💰

Desenvolvido em React Native + TypeScript, com banco SQLite local, notificações de lembrete e arquitetura em camadas, com testes automatizados das regras de negócio.

Projeto de Programação Mobile na UniRuy Wyden, com o Adilson Moreira Costa Filho e orientação do professor Vagner Oliveira Pimentel Pereira.
